# Kernel Libre Mx

Sitio estático preparado para GitHub Pages.

## Estructura
- `index.html` — portada
- `cursos.html` — cursos
- `blog.html` — blog
- `acerca.html` — acerca de mí
- `css/style.css` — diseño terminal responsive
- `js/main.js` — JavaScript
- `cursos/` — páginas individuales de cursos
- `blog/` — entradas individuales del blog

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `TUUSUARIO.github.io`.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. En Settings → Pages selecciona `Deploy from a branch`.
4. Selecciona `main` y `/ (root)`.
5. Guarda y espera a que GitHub publique el sitio.
